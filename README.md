# Moja Strona - Portfolio PL

Nowa wersja mojego osobistego portfolio — lekki, statyczny serwis napisany wyłącznie w **HTML/CSS/JS** bez frameworków. 
Prezentuję tu wybrane projekty (m.in. DIY Ambilight, serwer Minecraft) oraz uczę się frontendu w praktyce.

**Live:** [https://kujdzik.pl](https://kujdzik.pl)

---

## Najważniejsze
- **Architektura:** proste pliki statyczne + router oparty o hash do nawigacji.
- **Responsywność:** układ dopasowany do desktopu i telefonów.
- **Hosting:** własny serwer (Nginx), aktualizacje ręczne z repo (docelowo ma działać z GitHub Actions).


# My Website - Portfolio ENG

A refreshed version of my personal portfolio — a lightweight, static website built entirely with **HTML/CSS/JS**, without any frameworks.
It showcases selected projects (including a DIY Ambilight setup and a Minecraft server) and serves as a hands-on way for me to learn frontend development.

**Live:** [https://kujdzik.pl](https://kujdzik.pl)

---

## Highlights
- **Architecture:** simple static files + hash-based router for navigation.
- **Responsiveness:** layout optimized for both desktop and mobile devices.
- **Hosting:** self-hosted on an Nginx server, manually updated from the repository (to be automated via GitHub Actions).

⚠️ The website is currently available only in Polish, but I’m working on the English version. ⚠️
